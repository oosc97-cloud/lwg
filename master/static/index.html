서버 추가 방법 (자동 등록)

각 서버에 마스터 연동용 에이전트를 설치할 때 이 마스터 주소를 넣으면, 설치가 끝나는 즉시 아래 목록에 자동으로 나타납니다.
새 서버 설치 (각 서버에서 root로 실행, 설치 파일을 이 마스터에서 받음):
에이전트 업그레이드 (이미 설치된 서버에서 root로 실행, 마스터 주소·스캔 결과 유지):
에이전트가 5분마다 마스터에 신호를 보내므로 서버 IP가 바뀌어도 자동으로 따라갑니다. 마스터 서버에서 에이전트 포트(15892)로, 에이전트에서 마스터 포트로 서로 접속되어야 합니다.
주소로 직접 추가 (자동 등록을 쓸 수 없을 때만)
여러 대는 한 줄에 하나씩 "주소 [이름]" 형식으로 적으세요. 포트를 생략하면 15892를 씁니다.
